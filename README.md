# LIAR EYE｜ライアーアイ

発言を読み比べて、たったひとりのうそつきを見破る論理パズルゲーム。

**公開ページ:** https://tt-sensei.github.io/LIAR-EYE/

## ゲームのルール

- 登場人物は、ナビキャラサイトの6人（りく・そら・かい・さく・つき・なみ）。
- それぞれの人物は、ほかの人が「正直者」か「うそつき」かについて発言する。
- 正直者は本当のことを言い、うそつきは必ずうそを言う。
- うそつきは必ずひとり。発言を照らし合わせ、条件に合う人物を選ぶ。
- 答えを選ぶと、正解と考え方の解説を確認できる。ヒントは段階的に表示される。

## 問題構成

全30問。問題一覧では難易度でしぼりこめる。

- **LEVEL 1 — OBSERVATION:** 発言を読み、自分についての発言や基本的な関係に注目する。
- **LEVEL 2 — CONNECTION:** 複数の証言をつなげ、矛盾がないかを確かめる。
- **LEVEL 3 — DEDUCTION:** 4〜6人の証言を組み合わせ、候補を一人ずつ検証する。

各問題は、正直者・うそつきの条件をプログラムで全候補について検証し、解がちょうど一つになるように確認する。問題を追加・変更したときは、解が一つだけか必ず再確認すること。

## キャラクター対応

| 記号 | キャラクター |
| --- | --- |
| A | りく |
| B | そら |
| C | かい |
| D | さく |
| E | つき |
| F | なみ |

人物の論理上の記号（A〜F）は、問題の条件や解説との対応を保つために使用している。画面ではキャラクター名と記号を併記する。

## 技術メモ

- 静的なHTML・CSS・JavaScriptで動作。サーバー側のPHPは使用しない。
- Kuroshiro + KuromojiをCDNから読み込み、漢字にふりがなを付ける。
- CDNや辞書を読み込めない場合も、問題本文は表示される設計。
- スマートフォン・タブレットでの操作を想定したレイアウト。

## 問題の品質チェック

新しい問題を追加するときは、次の点を確認する。

1. 「うそつきはひとりだけ」というルールに合う。
2. 解がちょうど一つで、当てずっぽうでなく証言から導ける。
3. ヒントが答えを直接明かさず、考え方を促す。
4. 解説が、答えが成り立つ理由を証言と結びつけて説明する。
5. キャラクターの名前・記号・画像が正しく対応している。
